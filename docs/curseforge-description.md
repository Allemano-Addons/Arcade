# Allemano Arcade: CurseForge description

## Summary (max 200 characters)

Small games for WoW Forever, in the Allemano look. Hangman first: guess the WoW word, alone or with a friend. More games on the way.

## Description (the long one)

**Small games for the waiting around.** Allemano Arcade is a window with games built for WoW Forever, in the same look as the other Allemano addons.

> **Alpha (0.1.0).** Hangman works. Connect Four, Rock Paper Scissors and Battleships are planned, and so is Hangman for a whole raid.

### Hangman

Guess the word one letter at a time before the attempts run out.

- **Random word:** WoW words from eight categories: raid bosses, dungeons, zones and cities, classes and specs, races and factions, professions, items and gear, lore and NPCs. Pick a category or **Anything**.
- **Own word:** let a friend type a word (the letters are hidden) and an optional hint, hand over the computer and guess.
- A clickable keyboard, the wrong letters, six attempts and a danger bar. **Hint** shows one letter and takes an attempt; **Give up** shows the word.
- Your statistics (rounds, wins, win rate and streak) and the last ten words, saved per character.

### Commands

`/arcade` (or `/aa`) opens the games. `/arcade hangman` goes straight to Hangman.

### Good to know

- Made for **WoW Forever** (interface 16001). Needs no other addon.
- No data leaves the game. The addon sends nothing to any website.
