# Credits

**Allemano Arcade** is part of Allemano Addons (https://allemano.org).

## How it is made

Designed, directed and tested by Allemano. Much of the code is written with AI assistance (Claude, by Anthropic) under that direction. Releases are tested in the game before they are published, and the changelog says what changed.

## Third-party code

Allemano Arcade contains no third-party code or libraries. It uses the World of Warcraft API and, when another addon has registered it, the Expressway font through LibSharedMedia. It uses the game's own icons by path and ships only its own pictures (the mark, the icon and the rounded corners).
